# Carreira FC

Jogo web de simulação de carreira de jogador de futebol.

## Como jogar
1. Abra `index.html` em um navegador.
2. Crie seu jogador.
3. Escolha a nacionalidade.
4. Os clubes da nacionalidade escolhida são priorizados na escolha da base.
5. Jogue temporadas, tome decisões, simule partidas, negocie transferências e acompanhe o histórico.

## Observação sobre escudos
Os escudos são carregados pela internet a partir do `football-logos.cc`. Portanto, a primeira execução precisa de conexão com a internet para exibi-los.

## Salvamento
A carreira é salva no `localStorage` do navegador pelo botão 💾.
